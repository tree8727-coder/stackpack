1. 콤보 — 조합 하나 = 업무 하나

💥 무한 콘텐츠 공장

📢 마케터중급
uv ➔ ImageMagick ➔ FFmpeg ➔ n8n

대본만 있으면 파이썬이 카드뉴스 이미지를 찍어내고 FFmpeg가 릴스·쇼츠로 병합한 뒤 n8n이 SNS에 자동 발행합니다. 포토샵·프리미어 없이 콘텐츠 100장을 30분 안에 뽑아냅니다.

설치 (클릭하면 복사)
winget install astral-sh.uv
winget install ImageMagick.ImageMagick
winget install Gyan.FFmpeg
winget install --id n8n-io.n8n
실행
uv run examples/cardnews.py && ffmpeg -framerate 1/3 -i out/slide_%d.png -r 30 -pix_fmt yuv420p out/shorts.mp4

또는 한 줄로: uv run build.py install content-factory --yes

AI 프롬프트: 1인 창업가를 위한 마케팅 카드뉴스 4장을 [헤드라인 / 본문 / 강조색 HEX] 형태의 JSON으로만 줘. 이 데이터로 이미지를 자동 생성할 거야.

시간비용(포토샵 구독료)

💥 경쟁사 리포트 연금술

📈 데이터/리서치고급
Firecrawl ➔ jq ➔ sqlite-utils ➔ Pandoc

경쟁사 사이트를 통째로 긁어와 필요한 필드만 발라내고 로컬 DB에 쌓은 뒤, 경영진 보고용 PDF로 변환해 매주 배달합니다. 하루 2시간짜리 시장조사가 명령 한 줄이 됩니다.

설치 (클릭하면 복사)
winget install OpenJS.NodeJS.LTS
npm install -g @mendable/firecrawl-cli
winget install jqlang.jq
winget install astral-sh.uv
uv tool install sqlite-utils
winget install JohnMacFarlane.Pandoc
실행
firecrawl scrape https://경쟁사.com | jq '.content' | sqlite-utils insert data.db competitors -

또는 한 줄로: uv run build.py install insight-alchemy --yes

AI 프롬프트: 아래 크롤링한 경쟁사 JSON 데이터를 분석해서, 우리가 공략할 고객 불만 포인트 3가지와 차별화 전략을 뽑아내줘.

시간리서치 외주비용

💥 고스트 임플로이

🤖 AI/자동화고급
Browser-use ➔ Playwright ➔ LangGraph

API가 없는 레거시 ERP나 낡은 구형 사이트에 AI가 직접 로그인해 마우스를 클릭하며 정산·주문 작업을 처리합니다.

설치 (클릭하면 복사)
uv pip install browser-use playwright
uv run --with playwright python -m playwright install chromium
winget install astral-sh.uv
uv pip install langgraph
실행
uv run --with browser-use agent.py

또는 한 줄로: uv run build.py install ghost-employee --yes

AI 프롬프트: Browser-use로 [사이트]에 로그인해서 어제자 주문 목록을 CSV로 내려받는 스크립트를 써줘. 실패하면 3번까지 재시도하도록.

웹 노가다RPA 라이선스비

💥 무료 사내 AI 직원

🤖 AI/자동화중급
Ollama ➔ Dify ➔ n8n

회사 PDF를 학습한 CS 봇을 내 PC의 로컬 LLM으로 굴립니다. API 비용 0원, 데이터 외부 유출 0건. n8n으로 카톡·슬랙에 연결합니다.

설치 (클릭하면 복사)
winget install Ollama.Ollama
winget install Docker.DockerDesktop
git clone https://github.com/langgenius/dify.git
docker compose -f dify/docker/docker-compose.yaml up -d
winget install --id n8n-io.n8n
실행
ollama run llama3.2

또는 한 줄로: uv run build.py install local-brain --yes

AI 프롬프트: Dify에서 회사 복지제도 PDF를 학습시켜 직원들이 자연어로 물어보는 FAQ 봇을 만드는 설정 절차를 단계별로 설명해줘.

비용(AI구독료)비용(CS인건비)데이터 보안

💥 AI 마케팅팀 고용

📢 마케터고급
CrewAI ➔ Ollama ➔ Firecrawl

'리서처 → 라이터 → 검토자' 역할을 나눠 가진 AI 에이전트들이 서로 대화하며 블로그 글 한 편을 끝까지 완성합니다. 1인 창업가가 팀장이 되는 지점입니다.

설치 (클릭하면 복사)
uv tool install crewai
winget install Ollama.Ollama
winget install OpenJS.NodeJS.LTS
npm install -g @mendable/firecrawl-cli
실행
uv run --with crewai my_agents.py

또는 한 줄로: uv run build.py install agent-crew --yes

AI 프롬프트: 마케터 AI야, 리서처 AI가 Firecrawl로 가져온 데이터를 바탕으로 블로그 글을 써줘. 검토자 AI는 과장된 표현을 찾아 지적해.

인건비(팀원 대체)품질 검수 시간

💥 회의록 → 보고서 1초 변환

🧠 PM/기획자초급
glow ➔ Pandoc ➔ Stirling-PDF

메모장에 대충 써놓은 마크다운 회의록을 터미널에서 미리 보고, 바로 PDF·워드·HTML 보고서로 변환합니다. 2시간짜리 보고서 작업이 10초가 됩니다.

설치 (클릭하면 복사)
winget install charmbracelet.glow
winget install JohnMacFarlane.Pandoc
winget install Docker.DockerDesktop
docker run -d -p 8080:8080 frooodle/s-pdf:latest
실행
glow meeting.md && pandoc meeting.md -o report.pdf

또는 한 줄로: uv run build.py install paper-shredder --yes

AI 프롬프트: 아래 두서없는 회의 녹취록을 [배경 / 결정사항 / 액션아이템 / 담당자 / 기한] 마크다운 구조로 정리해줘.

시간보고서 작성 노동

까만 터미널을 Git 상태·언어 버전이 색으로 보이는 사령실로 바꾸고, 키보드만으로 수천 개 파일을 날아다니는 환경을 만듭니다. 다른 모든 콤보의 바닥입니다.

Add-Content $PROFILE 'Invoke-Expression (& { (zoxide init powershell | Out-String) })'
winget install junegunn.fzf
winget install BurntSushi.ripgrep.MSVC
winget install sharkdp.bat
winget install JesseDuffield.lazygit
winget install Fastfetch-cli.Fastfetch
실행
rg --line-number '검색어' | fzf --preview 'bat --color=always {1} --highlight-line {2}'

또는 한 줄로: uv run build.py install hacker-desk --yes

AI 프롬프트: (설치만 하면 됩니다. 터미널을 여는 순간 체감됩니다.)
