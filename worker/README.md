# 집계 서버

**받는 것: 사고 번호와 횟수, 그리고 클라이언트가 만든 난수 설치 ID.**
코드·파일 이름·경로·IP·대화는 받지 않습니다.

**사용자는 이 서버를 읽지 않습니다.** 읽기는 깃허브의 공개 집계 파일에서 합니다.
그래서 이 서버가 죽어도 프로그램은 그대로 돕니다.

## 왜 서버를 두나

혼자 쓰는 순위(내 컴퓨터에서 자주 걸리는 것)는 서버 없이 됩니다.
**전체에서 무엇이 자주 걸리는지**는 모으지 않으면 알 수 없고,
그게 「초록불 보고서」의 표본이 됩니다.

## 돈이 나갈 길을 코드로 막았습니다

무료 등급을 자기 설정으로 태우는 것이 정확히 우리 사고 **E13** 입니다.
그래서 하루 요청 상한(`하루상한`)을 코드에 박고, 넘으면 조용히 버립니다.

## 조작 방지

숫자는 **순서에만** 쓰입니다. 무엇이 카탈로그에 들어가고 빠지는지는 영원히
사람이 정합니다. 한 설치가 하루에 올릴 수 있는 양에도 상한이 있습니다.

## 배포

    npx wrangler kv namespace create KV      # id 를 wrangler.toml 에 적는다
    npx wrangler deploy
